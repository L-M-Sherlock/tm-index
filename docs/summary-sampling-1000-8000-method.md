# 1,000～8,000 字符译文总结抽样检查方法

本轮为 `short-summary-audit-20261103`，检查已收录译文、翻译节选和译编的现有总结。正文长度沿用目录 `read_chars`，是完整可见文本的字符数，包含标点等，并非只数汉字。范围为 `1000 <= read_chars < 8000`，不含正文恰为 8,000 字符的文章。

|正文字符层（左闭右开）|总体篇数|抽样篇数|总体权重|
|---|---:|---:|---:|
|1,000～2,000|418|15|31.31%|
|2,000～3,000|295|15|22.10%|
|3,000～5,000|330|15|24.72%|
|5,000～8,000|292|15|21.87%|
|合计|1,335|60|100%|

每层先按文章数值 ID 升序排列，使用同一个 Python `random.Random(20261103)` 按上述层序各无放回抽取 15 篇，再按 ID 排列抽中项。清单在任何总结审阅之前固定，不按主题、标题、旧稿长度或疑似问题选择样本，不替换来源难找的文章。

60 篇样本正文共 218,278 字符。源文件从只读备份仓库的历史提交 `34afa85c` 提取，逐篇确认原始 JSON 的 SHA-256、正文 HTML 的 SHA-256 和可见正文字符数均与现有目录所记录的原始来源一致。全部样本来源可用。当前备份中部分正文已经变化，本轮评估绑定总结生成时的原始版本。

初审和独立复核均继承本次会话的 GPT-6，明确配置 reasoning effort 为 max。实际有三位初审实例及两位独立复核实例；为了沿用均衡分配工具，每位初审实例承接两个 assessor 角色标签，不能把六个标签描述成六位独立代理。任一初审实例均不担任复核者。主代理负责检查结论与关键证据，并对分歧回查正文裁定。

每位审阅者先独立逐块阅读全文，保存带原文位置的主要观点提纲，之后才打开该篇现有总结。复核者保存自己的独立初判之后才比较初审意见。两份初判和原始提纲保留，分歧另写裁定，不通过改写初判制造一致。

判定沿用[抽样检查流程](summary-sampling-audit.md)：adequate 为主要观点覆盖充分，undercovered 为主要观点覆盖不足，distorted 为实质失真。省略次要例子、重复论述、普通细节和非核心数字不单独算不合格；不因总结篇幅短而判不合格。反向链接和纯导航不当作文章主动论证。任何来源或结构校验都不能代替独立语义复核。

各层问题率为（覆盖不足篇数＋实质失真篇数）÷15，同时报告 Wilson 95% 区间，不作有限总体修正。总体点估计按各层总体篇数/1,335 加权；不把 60 篇样本的简单混合比例作为总体估计，不据抽样结果对未抽中的单篇文章作判断。每层样本较小，区间用于体现不确定性，不作精确排名。

公开结果写入新的 `data/summary-sampling-audit-1000-8000-20261103.json`，保留上一轮报告。当前总结、目录、网页和导出代码均以哈希保护。本轮仅诊断，结果不自动写回总结或发布网站。

运行于 WSL Python；准备命令如下：

```sh
python3 scripts/summary_sampling_audit.py prepare \
  --source-dir .work/short-audit-sources/snapshots \
  --source-manifest .work/short-audit-sources/source-manifest.json \
  --recovery-dir .work/short-audit-sources/raw \
  --work-dir .work/short-summary-audit-20261103 \
  --run-id short-summary-audit-20261103 --date 2026-11-03 \
  --seed 20261103 --per-stratum 15 --bounds 1000 2000 3000 5000 8000 \
  --model gpt-6 --reasoning-effort max \
  --report-path data/summary-sampling-audit-1000-8000-20261103.json
```

准备只运行一次。后续用同一工作目录执行 `check` 和 `report`，不重新抽样。
